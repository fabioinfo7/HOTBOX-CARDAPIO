# HOTBOX V8 — Correção Mobile Pedidos + Chat

## Pedidos
- No celular, a página usa sempre cards; a tabela/lista continua disponível apenas no desktop.
- Cabeçalho mobile reorganizado.
- Botão de novo pedido ocupa espaço adequado para toque.
- Alarme vira botão compacto.
- Cards, alertas e botões ficam em uma coluna sem estourar a largura.
- Ações têm alvo de toque maior.

## Chat
No topo da conversa mobile existem quatro ações sempre visíveis:
1. Manual / Robô — alterna imediatamente o atendimento.
2. Automáticas — abre Mensagens automáticas/Respostas rápidas.
3. Pedidos — abre Pedidos em andamento.
4. Gerar IA — gera pedido usando a conversa.

O painel móvel continua contendo todas as funções do desktop e agora também mostra claramente:
- estado Manual ou Robô;
- botão "Mudar para manual" / "Ativar robô";
- aba Mensagens automáticas;
- aba Pedidos em andamento.

Desktop permanece com o layout e recursos existentes.
